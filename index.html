Privacy and storage

Your entries are stored in this browser's local storage. They are not sent to a server by this app. Clearing browser data, using incognito mode, or uninstalling/resetting the browser can erase them. Keep backups.

For a true AI chat, connect a model through a private backend. Never put an AI API key directly in this HTML file. This build deliberately works offline without an API key.
